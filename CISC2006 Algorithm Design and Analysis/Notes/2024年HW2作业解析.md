## 第 1 题　用快速幂在 $O(\log n)$ 时间内计算 $a^n$

每次把指数减半。设 $q=\lfloor n/2\rfloor$，只做一次递归求 $t=a^q$。若 $n=2q$，答案是 $t^2$。若 $n=2q+1$，再多乘一次 $a$ 即可。[原题第 1 页](../HW_verson2/hw2.pdf#page=1)

```text
power(a, n):
    if n == 0: return 1
    t = power(a, n // 2)
    if n 是偶数: return t * t
    return t * t * a
```

**用 $2^{13}$ 手算。** 调用时指数依次为 `13 → 6 → 3 → 1 → 0`。返回时从 $2^0=1$ 开始，依次得到 $2^1=2$、$2^3=2^2\times2=8$、$2^6=8^2=64$、$2^{13}=64^2\times2=8192$。半次幂只计算一次，两个乘数都使用已经算好的 $t$。

偶数、奇数两种公式覆盖全部正整数。根据题目的常数时间算术假设，每层只做常数次运算，递推为 $T(n)=T(\lfloor n/2\rfloor)+O(1)$，时间为 $O(\log n)$，递归栈占 $O(\log n)$。

## 第 2 题　用强归纳法证明 $T(n)=O(n)$

题设为 $1\le n\le3$ 时 $T(n)\le c$，$n\ge4$ 时

$$
T(n)\le T(\lfloor n/2\rfloor)+T(\lfloor n/4\rfloor)+cn.
$$

两个子问题的规模相加至多为 $3n/4$。试着证明 $T(n)\le Kn$，代入后留出的 $Kn/4$ 需要覆盖本层的 $cn$，因此选 $K=4c$。[原题第 2 页](../HW_verson2/hw2.pdf#page=2)

1. **基础情形。** 对 $n=1,2,3$，$T(n)\le c\le 4cn$。
2. **归纳假设。** 对所有 $1\le m<n$，均有 $T(m)\le4cm$。
3. **归纳步骤。** 当 $n\ge4$ 时，两个取整后的规模均在 $[1,n-1]$ 内，代入归纳假设即可得到下式。

$$
T(n)\le4c\lfloor n/2\rfloor+4c\lfloor n/4\rfloor+cn
\le 2cn+cn+cn=4cn.
$$

所以对所有正整数 $n$ 都有 $T(n)\le4cn$，得证 $T(n)=O(n)$。

## 第 3 题　两个序列的交集大小

输入的两个序列各有 $n$ 个元素，各自内部的值互异。先将两序列分别升序排序，再用指针 $i,j$ 同步扫描。相等时计数加一，并同时前进。若一边的值较小，就只前进那一边，因为它不可能等于另一边当前或以后的任何值。[原题第 3 页](../HW_verson2/hw2.pdf#page=3)

```text
intersectionSize(A, B):
    将 A、B 分别按升序排序
    i = 0, j = 0, count = 0
    while i < len(A) and j < len(B):
        if A[i] < B[j]:
            i += 1
        else if A[i] > B[j]:
            j += 1
        else:
            count += 1
            i += 1
            j += 1
    return count
```

例如排序后 $A=[1,4,7,9]$、$B=[1,4,6,8]$。先匹配 1 和 4，再比较 7 与 6（跳过 6）、7 与 8（跳过 7）、9 与 8（跳过 8）。$B$ 耗尽，答案是 **2**。排序用 $O(n\log n)$，扫描时每个指针最多前进 $n$ 次，总时间为 $O(n\log n)$。

## 第 4 题　数逆序对

数组中一对位置 $(i,j)$ 满足 $i<j$ 且 $A[i]>A[j]$，就贡献一个逆序对。原题分两问，先数左右两段之间的逆序对，再用这一步解决整个数组。[原题第 4 页](../HW_verson2/hw2.pdf#page=4)

### (a) 两个有序数组之间如何在线性时间内计数？

从左到右合并两个有序数组 $L,R$。若 $L[i]\le R[j]$，先取 $L[i]$。若 $L[i]>R[j]$，则 $L[i],L[i+1],\dots$ 全部大于 $R[j]$，一次加上 **$\operatorname{len}(L)-i$**，然后取走 $R[j]$。这里的 $i$ 从 0 开始。下面同时返回合并结果，供第 (b) 问复用。

```text
mergeCount(L, R):
    i = 0, j = 0, count = 0, M = 空数组
    while i < len(L) and j < len(R):
        if L[i] <= R[j]:
            把 L[i] 追加到 M
            i += 1
        else:
            count += len(L) - i
            把 R[j] 追加到 M
            j += 1
    把 L、R 中尚未读完的元素依次追加到 M
    return (M, count)
```

**手算。** 取 $L=[2,4]$、$R=[1,3]$。遇到右边的 1，左边剩下的 2、4 都比它大，一次加 2。接着取 2，计数不变。遇到右边的 3，左边还剩 4，再加 1。最后得到 $[1,2,3,4]$，跨段逆序对共 **3** 个，即 $(2,1),(4,1),(4,3)$。相等时走取左侧的分支，因为逆序的条件是严格大于。

每个元素只读出一次，时间与两个数组的长度之和成正比。

### (b) 输入数组还没有排好，怎么数？

按**原下标**从中间分开。把逆序对按两个端点的位置分为三类。两个端点可同在左半、同在右半，也可分处两半。前两类交给递归，第三类交给上面的 `mergeCount`。

```text
sortCount(A):
    if len(A) <= 1: return (A, 0)
    mid = len(A) // 2
    (L, leftCount)  = sortCount(A[:mid])
    (R, rightCount) = sortCount(A[mid:])
    (M, crossCount) = mergeCount(L, R)
    return (M, leftCount + rightCount + crossCount)
```

例如 $A=[4,2,1,3]$，原左半 $[4,2]$ 内有 1 对，右半 $[1,3]$ 内有 0 对。两边排好后刚好是 (a) 的例子，跨段有 3 对，所以总数为 **$1+0+3=4$**。每一层合并总共花 $O(n)$，一共 $O(\log n)$ 层，总时间 $O(n\log n)$。

## 第 5 题　酒店的 $k$ 间房够不够？

每个预订产生两个事件。入住使占用数加 1，退房使占用数减 1。按时间扫一遍，就能知道同一时间最多需要多少间房。题面只给入住日和离店日，没有规定同日事件的顺序。下面把入住区间记为 $[a_i,d_i)$，假设退房日当天可以把房间交给新客，因此同日**先退房，再入住**。[原题第 5 页](../HW_verson2/hw2.pdf#page=5)

```text
enoughRooms(bookings, k):
    events = 空数组
    for (a, d) in bookings:
        if a == d: continue       // [a,a) 不占用房间
        追加 (a, +1) 和 (d, -1) 到 events
    按 (日期, 变化量) 升序排序 events    // 同日 -1 排在 +1 前
    used = 0
    for (day, delta) in events:
        used += delta
        if used > k: return "NO"
    return "YES"
```

例如三笔预订为 $[1,3)$、$[2,4)$、$[3,5)$。

| 日期 | 按顺序处理事件 | 处理后的占用数 |
| --- | --- | --- |
| 1 | 第 1 位客人入住 | 1 |
| 2 | 第 2 位客人入住 | 2 |
| 3 | 第 1 位先退房，第 3 位再入住 | $2\to1\to2$ |
| 4 | 第 2 位退房 | 1 |
| 5 | 第 3 位退房 | 0 |

最高同时占用 **2 间**，所以 $k=2$ 输出 YES，$k=1$ 输出 NO。如果某时刻入住人数超过 $k$，就一定缺房。如果占用数始终不超过 $k$，每位新客到来时就都有空房。至多有 $2n$ 个事件，排序用 $O(n\log n)$、扫描用 $O(n)$，辅助空间 $O(n)$。如果另有规定要求客人在离店日仍占房，就用闭区间处理，保留同日起讫的预订，并把同一天的入住排在退房之前。

## 第 6 题　将值域为 $[0,n^2-1]$ 的 $n$ 个整数在线性时间内排序

范围上界保证每个整数都能用**两位 $n$ 进制**表示。对每个 $a$ 计算高位 $x=\lfloor a/n\rfloor$ 和低位 $y=a\bmod n$，则 $a=xn+y$，且 $x,y$ 都在 $[0,n-1]$ 内。每趟只需要 $n$ 个桶。先按低位分桶，再按高位**稳定地**分桶。[原题第 6 页](../HW_verson2/hw2.pdf#page=6)

```text
stablePass(A, key, n):
    准备 n 个空桶，编号为 0 到 n-1
    for a in A:
        把 a 追加到编号 key(a) 的桶末尾
    从 0 号桶读到 n-1 号桶，每个桶按进入顺序读出
    return 读出的数组

radixSort(A):
    n = len(A)
    if n <= 1: return A
    B = stablePass(A, 低位 a % n, n)
    return stablePass(B, 高位 a // n, n)
```

用先前的例子 $n=5$、$A=[17,9,15,6,2]$ 手算。$17=3\times5+2$，所以 17 的低位是 2、高位是 3。其余数字同理。

| 桶号 | 第一趟，按低位放入 | 第二趟，按高位放入 |
| --- | --- | --- |
| 0 | 15 | 2 |
| 1 | 6 | 6，9 |
| 2 | 17，2 | 空 |
| 3 | 空 | 15，17 |
| 4 | 9 | 空 |

第一趟读出 $B=[15,6,17,2,9]$。第二趟**按这个新顺序**分桶，读出 $[2,6,9,15,17]$。看高位同为 3 的 15 和 17，第一趟已使 15 排在 17 前面，第二趟在同一个桶内保留这个次序。因此高位小的数整体靠前，高位相同的数按低位升序，得到的恰是数值升序。

每一趟初始化 $n$ 个桶，放入再读出总共 $n$ 个元素。桶尾追加按 $O(1)$ 计算（有尾指针的链表可保证），一趟 $O(n)$，两趟仍为 **$O(n)$ 时间、$O(n)$ 辅助空间**。

## 第 7 题　实现六种排序并比较运行时间

原题要求每种排序单独写成函数，输入从文件读入，是一组互异整数。六个函数都返回从小到大排好的数组，主程序逐一检查并计时。**堆排序要用优先队列，快排的枢轴要取当前子数组中三个随机元素的中位数。** [原题第 7 页](../HW_verson2/hw2.pdf#page=7)

| 算法 | 这一版每一步做什么 | 时间复杂度 |
| --- | --- | --- |
| 插入排序 | 保存待插入元素，将有序前缀中比它大的元素向右挪，再填入空位 | 已有序 $\Theta(n)$，最坏 $\Theta(n^2)$ |
| 冒泡排序 | 相邻逆序就交换，每趟将剩余最大值送到末端。一趟无交换即可停止 | 有提前停止时，已有序 $\Theta(n)$，最坏 $\Theta(n^2)$ |
| 选择排序 | 每轮扫描剩余区间，选出最小值，放到该区间首位 | 各种输入均需 $\Theta(n^2)$ 次比较 |
| 堆排序 | 建最小堆，连续取出堆顶，将结果追加到新数组 | 建堆 $\Theta(n)$，全部取出最坏 $\Theta(n\log n)$ |
| 归并排序 | 二分，递归排好左右两半，再用双指针合并到辅助数组 | 这版每层都合并，时间 $\Theta(n\log n)$ |
| 快速排序 | 随机抽取三个不同位置，取三个键的中位数为枢轴，按枢轴划分区间。长度为 2 时直接比较 | 期望 $\Theta(n\log n)$，最坏 $\Theta(n^2)$ |

**实际跑一次会看到什么？** 下表使用同一组 800 个互异整数（0 到 799），分别按升序、逆序和随机顺序输入。数值是本机 Python 3.9.6 上每种情况运行 7 次的中位时间，单位为毫秒。每个函数内部复制输入，计时包含这次复制，文件读取和结果校验在计时之外。随机数组用种子 2024 打乱，7 次快排的种子依次为 2024 至 2030。

| 算法 | 升序 | 逆序 | 随机 |
| --- | ---: | ---: | ---: |
| 插入排序 | 0.053 | 14.403 | 6.971 |
| 冒泡排序 | 0.023 | 21.386 | 14.430 |
| 选择排序 | 6.450 | 6.926 | 6.559 |
| 堆排序 | 0.086 | 0.084 | 0.085 |
| 归并排序 | 0.544 | 0.568 | 0.705 |
| 快速排序 | 0.750 | 0.754 | 0.762 |

升序输入下，插入排序无需搬动元素，冒泡排序首趟就能结束。逆序输入让两者产生大量移动或交换。选择排序的剩余区间长度只由轮数决定，三种输入的耗时因此较接近。堆排序调用了标准库 `heapq`，它和手写 Python 循环的常数开销也会影响实测结果。

<summary>展开第 7 题的完整 Python 参考程序</summary>

把以下代码保存为 `sort_hw2.py`。示例文件 `input.txt` 可写入 `8 3 10 2 7`，空格或换行均可，首个整数也是数据。运行 `python3 sort_hw2.py input.txt` 即可。程序将每个输出与同一输入的标准排序结果核对，再报告耗时。

```python
import heapq
import random
import sys
from pathlib import Path
from time import perf_counter


def InsertionSort(values):
    a = list(values)
    for i in range(1, len(a)):
        value = a[i]
        j = i - 1
        while j >= 0 and a[j] > value:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = value
    return a


def BubbleSort(values):
    a = list(values)
    for end in range(len(a) - 1, 0, -1):
        swapped = False
        for i in range(end):
            if a[i] > a[i + 1]:
                a[i], a[i + 1] = a[i + 1], a[i]
                swapped = True
        if not swapped:
            break
    return a


def SelectionSort(values):
    a = list(values)
    for i in range(len(a) - 1):
        min_index = i
        for j in range(i + 1, len(a)):
            if a[j] < a[min_index]:
                min_index = j
        if min_index != i:
            a[i], a[min_index] = a[min_index], a[i]
    return a


def HeapSort(values):
    heap = list(values)
    heapq.heapify(heap)
    result = []
    while heap:
        result.append(heapq.heappop(heap))
    return result


def MergeSort(values):
    a = list(values)
    auxiliary = [0] * len(a)

    def merge(left, middle, right):
        i, j, k = left, middle, left
        while i < middle and j < right:
            if a[i] <= a[j]:
                auxiliary[k] = a[i]
                i += 1
            else:
                auxiliary[k] = a[j]
                j += 1
            k += 1
        while i < middle:
            auxiliary[k] = a[i]
            i += 1
            k += 1
        while j < right:
            auxiliary[k] = a[j]
            j += 1
            k += 1
        a[left:right] = auxiliary[left:right]

    def sort(left, right):
        if right - left <= 1:
            return
        middle = (left + right) // 2
        sort(left, middle)
        sort(middle, right)
        merge(left, middle, right)

    sort(0, len(a))
    return a


def QuickSort(values):
    a = list(values)

    def sort(left, right):
        # 闭区间 [left, right]。只递归较短的一侧，另一侧在循环中处理。
        while right - left + 1 >= 3:
            sample = random.sample(range(left, right + 1), 3)
            pivot_index = sorted(sample, key=a.__getitem__)[1]
            pivot = a[pivot_index]
            a[pivot_index], a[right] = a[right], pivot
            cut = left
            for i in range(left, right):
                if a[i] < pivot:
                    a[cut], a[i] = a[i], a[cut]
                    cut += 1
            a[cut], a[right] = a[right], a[cut]
            if cut - left < right - cut:
                sort(left, cut - 1)
                left = cut + 1
            else:
                sort(cut + 1, right)
                right = cut - 1

        if left < right and a[left] > a[right]:
            a[left], a[right] = a[right], a[left]

    sort(0, len(a) - 1)
    return a


if __name__ == "__main__":
    values = [int(token) for token in Path(sys.argv[1]).read_text().split()]
    expected = sorted(values)
    random.seed(2024)
    for method in (InsertionSort, BubbleSort, SelectionSort,
                   HeapSort, MergeSort, QuickSort):
        start = perf_counter()
        result = method(values)
        millis = (perf_counter() - start) * 1000
        correct = result == expected
        print(f"{method.__name__:14} {millis:9.3f} ms  correct={correct}")
```
